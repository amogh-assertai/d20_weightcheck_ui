How this is calculated

Full formula, with today's actual numbers

Rule 1 - Every PASS is assumed correct. No review needed.

Rule 2 - Every FAIL / MISSING_DATA activity must be reviewed (marked System Error and/or Process Error) before it counts toward accuracy at all. Untouched activities are excluded, not counted as wrong.

Rule 3 - Once reviewed: System Error = Yes means the system itself got it wrong (a genuine solution error) - counted as incorrect. Process Error = Yes, or both marked No, means the system's call was right - counted as correct.

Edge case: if an activity is marked Yes for both System Error and Process Error, System Error takes priority (counted as incorrect).

Accuracy = (PASS + Correct non-pass) ÷ (PASS + Reviewed non-pass) × 100
= ({{ pass_count }} + {{ correct_non_pass }}) ÷ ({{ pass_count }} + {{ reviewed_non_pass }}) × 100
